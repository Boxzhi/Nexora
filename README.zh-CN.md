# Nexora

面向 Home Assistant 的可扩展本地意图与会话交互引擎。

当前版本：v0.4.0-preview（联合验收候选，非正式发布）。

发送 help 或 帮助 打开主菜单；exit 或 退出 关闭；0、back 或 返回 返回上一级；99、next 或 下一页 翻页；98、prev 或 上一页 返回前页。每页最多显示20个可用项目，1–20用于单项选择及组合路径；仅在存在相邻页时显示对应数字翻页项。英文不区分大小写。一级分类图标由注册目录配置。

保留现有业务意图库及原生 Intent Script。不提供供应商接口，不控制设备。仅显示已注册且符合 speech-only 检查的模块；执行前严格核对 Intent 和槽位，失败不交给大模型执行。单灯实体 ID 由本地已安装句式解析，不写入公开源码。灯具不支持亮度或色温时由原意图反馈实际能力。

安装：HACS 自定义仓库（Integration），或替换 custom_components/nexora。原 Nexora 集成配置保留，重启 Core 一次后验证。自定义目录 /config/nexora/catalogs/ 支持 JSON/YAML，重载集成生效。详见 [注册协议](docs/catalog.md)。

配套 CN IM Hub 测试分支支持原生快速查询、本地有序交互、普通 AI 三通道。未安装配套分支时 Nexora 本地菜单仍可用，但不保证微信调度并发。仅针对 HA Core 2026.11.3 接口开发；本候选版本尚待真实环境联合验收。AI 家庭查询保护是规则识别，不是严格权限沙箱；具有工具权限的备用代理可能执行漏匹配的指令。测试时请使用可信且受限的备用代理。

## 动态菜单

443 为注册能力基线，不再强制展示全部项目。灯具能力从本地严格识别的目标及 supported_color_modes 判断；已确认不支持的亮度、色温隐藏，设备关机、离线或暂时不可用不会移除其已确认支持的能力。目标映射按需缓存5分钟，状态属性在菜单生成时读取，无轮询。已知 Home v1.0.1 / Appliance v1.0.0 模板通过静态 AST 提取原生绑定，Lights v1.1.0 延续严格目标识别，无需额外文件。/config/nexora/bindings.yaml（可选）仅用于人工覆盖，null 强制隐藏；修改人工覆盖后重载 Nexora。未知模板、临时离线或实体缺失保持显示。

支持 1.2.1 这类相对当前菜单的数字路径，不能跨越查询或参数输入，无效路径不改变当前菜单。普通菜单不再显示示例句。追问覆盖菜单、语义匹配及配套 CN IM Hub 原生快速查询产生的固定水电气能力：账期、用量/费用澄清、账户切换。查询上下文5分钟、菜单10分钟、AI 会话映射30分钟。指定日期等动态参数及 AI 工具查询暂不共享业务上下文。全量脚本分别报告可见查询执行和隐藏项复核，不把隐藏自动算作失败或通过。

自动提取仅匹配已验证的模板结构，绑定字典内容允许变更。Intent Script 重新加载后，下次交互自动检测源码变化，不需要重载 Nexora，不执行探测查询、不新增轮询、不公开家庭实体。Home 原版窗户分支尚未实现，因此自动隐藏；马桶盖传感器保留独立语义。未来修改窗户查询逻辑后，不匹配已知结构则保守显示。水电气维持原行为。

联合验收与回滚：[docs/preview-acceptance.md](docs/preview-acceptance.md)。
