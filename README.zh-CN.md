# Nexora

面向 Home Assistant 的可扩展本地意图与会话交互引擎。

当前版本：v0.3.0-preview（开发预览）。

发送 help 或 帮助 打开主菜单；exit 或 退出 关闭；0、back 或 返回 返回上一级；9、next 或 下一页 翻页；prev 或 上一页 返回前页。英文不区分大小写。仅在提示中显示 help、exit 和 prev。一级分类图标由注册目录配置。

保留现有业务意图库及原生 Intent Script。不提供供应商接口，不控制设备。仅显示已注册且符合 speech-only 检查的模块；执行前严格核对 Intent 和槽位，失败不交给大模型执行。单灯实体 ID 由本地已安装句式解析，不写入公开源码。灯具不支持亮度或色温时由原意图反馈实际能力。

安装：HACS 自定义仓库（Integration），或替换 custom_components/nexora。原 Nexora 集成配置保留，重启 Core 一次后验证。自定义目录 /config/nexora/catalogs/ 支持 JSON/YAML，重载集成生效。详见 [注册协议](docs/catalog.md)。

限制：当前菜单仍可能等待 LLM 普通队列；支持数字菜单产生的基础水电气上下文追问，独立快速菜单通道及快速查询上下文同步后续开发。仅针对 HA Core 2026.11.3，v0.3.0-preview 尚待实际 HA 验收。此前 v0.1.0-preview 已验证水电气 136 项查询链路。

## 动态菜单

443 为注册能力基线，不再强制展示全部项目。灯具能力从本地严格识别的目标及 supported_color_modes 判断；已确认不支持的亮度、色温隐藏，设备关机、离线或暂时不可用不会移除其已确认支持的能力。目标映射按需缓存5分钟，状态属性在菜单生成时读取，无轮询。其他设备及成员使用可选 /config/nexora/bindings.yaml（见 examples/bindings.yaml），null 为明确未配置；未知绑定或实体暂时缺失保持显示。修改绑定后重载 Nexora 集成。

支持 1.2.1 这类相对当前菜单的数字路径，不能跨越查询或参数输入，无效路径不改变当前菜单。普通菜单不再显示示例句。基础追问仅覆盖数字菜单产生的水电气非动态参数查询：账期、用量/费用澄清、账户切换。查询上下文5分钟、菜单10分钟。普通对话仍透传，原 CN IM Hub 快速通道上下文不在本次范围。全量脚本分别报告可见查询执行和隐藏项复核，不把隐藏自动算作失败或通过。
