# Nexora v0.5.3-preview 验收

仅升级 Nexora；保留原四套 custom_sentences/zh-CN 与 intent_scripts 的8个 YAML、现有配置、CN IM Hub、AI Hub、SGCC Add-on。bindings.yaml 可选。备份后通过 HACS 安装已发布预览版并重启 Core。异常时恢复 v0.5.2-preview 完整目录并重启，不删除配置条目或 .storage。未发布前不要升级。

## 验收顺序

1. 发送 help 确认新版场景菜单、detail 确认原始完整菜单；旧数字路径仅在 detail 下使用。检查0返回、exit退出、参数输入与取消、同一会话追问及独立会话。
2. 场景专项：按新版菜单查询水电气综合概况、灯光状态、洗衣进度、空调运行状态、全屋环境及入户门状态；检查部分数据、设备关机、隐藏能力及真实数值。日期参数只输入一次；检查再查一次、上月呢、所有账户呢。
3. 独立只读全量探测：help 场景基线150（65/37/24/24），detail 原始基线443（136/144/78/85）。原 full_probe.js 从 detail 遍历。此前实机隐藏23项对应模拟可见149/420，并非通用门槛。自定义目录及动态可见性单独复核。数据缺失或状态限制不能当作完整数据通过。
4. 微信同一会话逐条发送 help、detail、help、我家水电气余额还有多少、有没有欠费的、需要充值吗、所有账户呢、余额呢；核对账户与指标。若 HA 专项通过但微信追问失败，核实实际路由与 conversation_id；外部原生 Intent 直达不共享 Nexora 上下文。
5. 发送 help 刷新映射后下载 Nexora 诊断，核查隐藏原因及聚合路由统计。诊断下载不触发查询。SGCC 重启恢复不属于本版修复。

脚本独立交付，不作为 Release 附件，不复制入运行目录。不发送控制或混合控制反例，不为了测试开启有控制权限的备用 Agent。HACS Topics / Brands 为独立收录检查，不绕过。真实 HA 和微信验收仍待用户执行。
