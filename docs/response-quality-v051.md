# v0.5.1 分阶段复核

基线 v0.5.0-preview (20314aa)。仅 Nexora。原始四套能力目录、8个外部 YAML、其他集成与 SGCC 不改动。

1. 共用只读回复格式化层，保留 HA IntentResponse 元数据及非 plain 回复。
2. 基于经过核实的原文契约进行场景整合；未知格式、部分失败、对象不一致保留原文。
3. 仅去除明确物理量的整数小数尾零，不舍入，不改金额精度。
4. query_quality 独立记录每个返回结果的质量；不等于路由次数，执行成功不代表数据完整。标注部分数据与时效限制，不填补缺失值。
5. HA 诊断下载包含内置能力 ID、状态及原因；不含原始绑定、家庭实体 ID、状态或对话内容。先发送 help 刷新映射再下载。真实隐藏原因仍需安装后核实。
6. 增加常用只读问句和混合请求边界；保留原生/标准查询、控制及 fallback 原权限。
7. 固定脱敏日志格式抽样回放、独立口语及反例、旧版全量测试。回复结构来自验收日志，仓库夹具使用脱敏标签与示例数值；不是新一轮实机验收或泛化盲测。
8. 发布预览版后独立验收包，需用户在 HA 与微信执行。
