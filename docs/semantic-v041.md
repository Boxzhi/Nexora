# 0.4.1 preview · 语义词库与分类（阶段一）

以 v0.4.0-preview 四套目录为唯一能力来源，按原始 Intent 和 Slots 生成 Profile（模块、对象、指标、账期、参数、账户）。不新建业务实体、Intent 或查询。所有 443 项纳入分类；409 项固定查询提供共享词库及受控完整句式；34 项参数化查询只分类，阶段三处理语义日期解析。灯光计数沿用原 Intent 的灯组口径。词库不参与当前运行，阶段二再接入匹配引擎。

语义单位不能互换：燃气余额（元）、阶梯余量（方）、表读数、历史用量和账单费用均是不同指标；空调设定温度与室温、入户门关闭与上锁也独立。账户未配置不生成别名。完整句式不删除否定词、对象、单位、时间或控制词。词库碰撞由自动化测试检查；阶段二引擎仍应对扩展目录/配置产生的碰撞明确澄清，不根据可用性猜测对象。

验证：分类唯一性、固定能力覆盖、二级账户边界、指标区分、词库内部碰撞。此阶段不改变已发布版本，不依赖 CN IM Hub/AI Hub。

## 阶段二：组合匹配接入

共享词库按原始能力 Profile 生成完整候选句式，保留旧版标准句和受控别名，单次索引查找，不进行模糊字符串匹配。显式询问前缀和句末语气词仅在边界归一化，不能删除单位、设备、账户、时间或否定词。新旧词库产生的多个候选返回本地澄清。严格原生优先级与原执行器不变。阶段三再处理参数化表达及更完整的歧义规则，阶段四才扩展上下文。阶段五优化未匹配查询保护。当前统计是静态语料自动化测试，不代表所有自然语言或真实环境准确率。

## 阶段三：歧义及动态日期

34项已注册水电气参数化能力通过完整句式识别，复用原菜单日期校验、原始 Intent/Slots 和只读执行器。支持中文年月日、今年/去年、数字年月日及明确 ISO 日期；不推断不存在的时间范围汇总或实物剩余量。不接受未来日期、非法月份、无效闰日。水务月度账单仅有今年/去年注册能力，显式其他年度不伪造查询。明确歧义和无效日期优先本地澄清；正常匹配仍保持原生 Intent 优先。所有日期以 HA 本地日期为准。默认主账户以及燃气无单位余额口语规则不变，显式方/立方米/吨/度不会转为余额。此阶段不新增上下文状态，后续阶段扩展。
复核补充：水务明确年份等于今年或去年时映射现有相对年度能力；去年/前年指定日用电转为原有完整日期能力。无年份月份费用不猜测年份。显式解析出的动态参数与原生识别不一致时，本地停止并澄清。

## 阶段四：本地上下文

四模块仅记录 Nexora 自身成功执行的注册能力；同一会话内明确对象/指标切换、重复查询和指定日期继承。保留5分钟 TTL、256 会话上限及 generation 防止迟到结果覆盖。澄清仅保存已注册选项，选择后仍通过严格只读执行。相对年份跨年拒绝沿用，明确不同设备类型不继承指标。跨集成快速查询不经过 Nexora，不能同步上下文；外部查询后请明确对象。无任意代词推断或 AI 记忆。
