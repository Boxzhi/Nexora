# 阶段九：独立语料与全量回归

人工固定标注正例、错误对象/单位/时间/控制反例及普通备用代理请求。测试实际 Agent 到严格原生 executor 的 mock 链路，不以生成词库作为独立语料。记录一次正确 dispatch、遗漏、错误 dispatch、旧版未覆盖数量及备用代理边界。保留原443项模拟 dispatch 与旧口语/反例全量测试。基准测量纯本地 planner 耗时和索引分配，不包含 HA 原生识别、I/O、设备实体状态或语音传输。测试数据均为 mock，真实 HA 验收留待第十阶段。
首轮独立语料结果48/68正确、0错误执行、20未命中；补强对象连接词、状态疑问形式、明确年度缴费、环境人体/水浸及常用设备指标。所有固定测试样本保留，不删改预期结果。注意本语料是开发过程中独立手工标注，修正后成为回归集，并非盲测泛化准确率。
